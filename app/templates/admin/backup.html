Экспорт (.zip)

Архив включает JSONL-дамп БД и всю папку media

  • Формат `v3`: `manifest.json`, `db/*.jsonl`, `media/**`
  • Восстанавливаются товары, баннеры, support-медиа и видео-постеры
  • Архив собирается на диске, без загрузки всего файла в память

Импорт (.zip / .json)

Восстановление из полного ZIP или legacy JSON

  • Внимание! Текущие данные БД будут заменены.
  • `.zip` восстанавливает и БД, и файлы из `media/`.
  • Legacy `.json` восстанавливает только БД, без медиафайлов.

Выберите `.zip` или legacy `.json`

Выбран legacy JSON: восстановятся только записи БД. Медиафайлы не вернутся.
