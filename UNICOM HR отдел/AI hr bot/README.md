# UNICOM HR отдел

Telegram-бот для анкетирования кандидатов и HR workspace для просмотра ответов.

## Что внутри

- Telegram conversation flow на Telegraf.
- Настраиваемые вопросы анкеты: письменный ответ или готовые варианты.
- Обязательные критерии для вариантных вопросов: непроходной вариант переводит кандидата в `Не подходит`.
- SQLite база кандидатов, сообщений, вопросов, ответов и admin notes.
- PostgreSQL-хранилище runtime-настроек: Telegram bot token.
- React/Vite workspace в стиле UNICOM Market: единая авторизация сотрудников через Market, фильтры, карточка кандидата, критерии, ответы анкеты, экспорт CSV.

## Быстрый запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте локальный конфиг:

   ```bash
   cp config.example.json config.json
   ```

3. Заполните в `config.json`:

   - `telegram.botToken` — токен от BotFather для первичного seed в PostgreSQL.
   - `postgres` — подключение к PostgreSQL для runtime-настроек HR workspace.
   - `workspace.marketBaseUrl` — базовый URL основного UNICOM Market для проверки общей сессии.
   - `workspace.marketWorkspaceUrl`, `workspace.hrWorkspaceUrl` — ссылки для переключателя workspace.

4. Запустите dev-режим:

   ```bash
   npm run dev
   ```

5. Откройте workspace:

   - UI: http://127.0.0.1:5173
   - API health: http://localhost:3000/health

## Production

```bash
npm run build
npm start
```

После build Express будет отдавать собранную админ-панель из `dist/`.

HR workspace не хранит отдельный пароль администратора. Все защищённые API-запросы проверяют сотрудника через `/admin/api/session` основного UNICOM Market.

Токен Telegram-бота меняется в разделе `Настройки` HR workspace. Секрет не возвращается в API-ответах, UI показывает только статус `задан/не задан`.

Вопросы анкеты также редактируются в `Настройки`: HR может добавлять, менять и удалять вопросы. Для вопросов с готовыми ответами можно включить `Обязательный критерий` и отметить, какие варианты считаются проходными.

## Вакансии и анкета

Вакансии зашиты в seed базы:

- Офис менеджер.
- Торговый представитель.

Анкета глобальная для всех вакансий. Бот задаёт вопросы по очереди. Во время ответа в Telegram показывается кнопка `Вернуться назад`; она удаляет предыдущий ответ и повторно отправляет соответствующий вопрос.
